# Best-of-random-candidates experiment

This historical exploratory experiment screens independently generated random
supports and retains the candidate with the largest mean entropy over balanced
cuts. It is **not** a greedy construction, is not used in the manuscript, and
should not be interpreted as an optimization algorithm.

The original development files referred to this as a “greedy” search. They are
preserved here under an accurate name so that the historical numerical exercise
remains inspectable without being confused with the publication workflow.
