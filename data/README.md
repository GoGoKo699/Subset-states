- `peak_verification_schedule.csv`: default local-check workloads.
- `fig5_random_qft_summary.csv`: random-support baseline for Figure 5(a).
- `fig5_almost_prime_unions.csv`: deterministic almost-prime points.

- `residue_matched_samples.csv`: all 12,000 paired constrained-null samples.
- `residue_entropy_bounds.csv`: residue populations and exact entropy ceilings.
